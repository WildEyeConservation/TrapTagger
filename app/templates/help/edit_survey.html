Here you are able to edit your survey in ten ways:
  • Classifier version: The current AI version used to classify the species contained in your survey is displayed here. If there is a newer version available, the update option becomes available. This will then re-classify the images in your survey using the latest classifier version. Thereafter you can either run an AI check check on your old annotation sets, where you can manually check the descrepancies between your labels and the new classifier's labels, or create a new annotation set using the new classifications. In the case of the latter, you can also use the comparison functionality in the results section to compare the new annotations to any old annotations you might have had.
  • Coordinates: Edit the coordinates of your sites. This can either be done manually (in decimal degrees format), or using a kml file. The latter is simply the Google Earth format. Just ensure that your placemark names match your site names in order for the system to know which one is which. Note that having coodinates fo your sites is entirely optional, and is only necessary for map based results or if you wish to include coordinates in you csv files.
  • Camera timestamps: Adjust each camera's clock by setting the timestamp of its first image to the correct time. This can be used to correct for incorrectly set up cameras. Please note that this can be done at any time, but it is recommended that you should do it right away before creating your first annotation set. This can be done at either a folder or camera level.
  • File Timestamps: Edit the timestamps of your images and videos. Please note that this can be done at any time, but it is recommended that you should do it right away before creating your first annotation set. The timestamps can be edited in three ways:
    • Missing Timestamps: If you have any images or videos without timestamps, you can add the timestamps here.
    • Extracted Timestamps: Here you can view and edit the timestamps that were extracted from an image or video if it was not possible to extract the timestamp from the image or video's metadata.
    • Edited Timestamps: View and edit the timestamps that were manually added to an image or video that had no timestamp or whose extracted timestamp was corrected.
  • Area: View and edit the area that your survey is located in. You have the ability to select an existing area or create a new area. You also have the ability to edit the name of the area the survey is associated with.
  • Advanced options: Select whether the system should ignore small detections or those in the sky. This reduces the number of false detections due to birds in exchange for some reduced accuracy.
  • Masks: View and edit the masks you have created during the annotation process. You can review what detections have been masked, and add, edit or remove masks as you see fit.
  • Static Detections: View and edit the detections that were marked as static. You can edit whether the idenitified static detections are correct or not. It is recommended that you do this before creating your first annotation set.
  • Calibration Images: Manage the reference images used to estimate detection distances. Calibration images are photographs of a person taken at known distances from the camera, and are required if you wish to run distance estimation on your sightings. You can work with them in two ways:
    • Edit Calibration Images: View the calibration images for each camera, adjust the bounding box around the calibration object, correct the recorded distance, or delete the calibration images.
    • Upload Calibration Images: Add new calibration images for one camera at a time, or in bulk by selecting a folder tree that contains calibration folders matched to your existing cameras. Filenames must contain a distance in metres (for example 5.jpg, 10m.jpg, or cal_5.5m.jpg). For a single-camera upload the folder itself can be named anything; for bulk upload, folders whose names contain "calibration" (case-insensitive) are detected automatically under each camera. Changes are applied when you save the survey.
  • Distance Estimation: Estimate the distance of animal detections from the camera using your calibration images and species-labelled trap detections. Select an annotation set whose species labelling is complete, choose one or more species to process, review the launch preview, and then launch distance estimation. Cameras need suitable calibration images before they can be processed. The resulting detection distances are what enable Distance Sampling and TTE Abundance analysis types in the Analysis section. Please note that launching distance estimation will process your survey, so any unsaved survey edits should be saved or discarded first.
