Detection function

The Detection function plot shows the fitted detection probability as a function of distance from the camera for the model selected on the Model selection tab.

How to read the plot:

  • Horizontal axis: Detection distance (metres), after any min/max truncation applied for the analysis.
  • Vertical axis: Estimated probability of detection at that distance.
  • Histogram / points: Observed detection distances (often shown in distance bins).
  • Fitted curve: The selected key function (uniform, half-normal, or hazard-rate, with any chosen adjustments).

A well-behaved fit typically declines from near 1 at zero distance (subject to left truncation and sample fraction) toward lower detection at greater distances. The shape should follow the histogram of observed distances reasonably closely; large mismatches may indicate truncation, sample size, or model-selection issues.

Use Export on this tab to download the detection-function image. The underlying R script is available via View R Script, and the Distance flatfile via Download CSV.
