Distance sampling

Distance sampling estimates the density of a single species (animals per km²) from camera-trap detections with measured distances and camera effort. It follows the camera-trap distance sampling (CTDS) approach implemented in the R Distance package.

Key requirements:

  • One species: Select a single species for each run. Density is estimated per species; pooled multi-species analysis is not supported.
  • Detection distances: Detections must have distance values, typically from depth estimation on calibration and trap images.
  • Study area: Enter the survey or stratum area in km² used as the Area column in the Distance flatfile.
  • Camera field of view: Enter the horizontal field of view in degrees. Sample fraction is calculated as FOV / 360.
  • Camera effort: Effort is operating time at each site divided by the snapshot interval (default 2 seconds). Sites with effort but no detections of the selected species are included in the analysis.
  • Time to independence: Detections at the same site are thinned so burst photos closer together than this interval count as one independent event (default 30 minutes). Set to 0 to disable thinning.

Optional settings:

  • Left / right truncation: Optional truncation distances in metres for the detection function.
  • Advanced options: Snapshot interval (seconds) used to convert operating time into CTDS effort units. Change only if your study used a different interval.

Data selection on the Datasets tab applies as for other R analyses: choose surveys and annotation sets, an optional date range, and sites on the Sites tab. For a single-survey estimate, select that survey rather than All.

Results include density, standard error, confidence interval, detection count (after independence thinning), site count, sample fraction, effective detection radius, and a detection function plot. Reliable inference generally requires sufficient camera sites and independent detections; very few sites produce wide confidence intervals.

View the underlying R script with View R Script, or download the Distance flatfile CSV with Download CSV. Click Generate Results to run the analysis. The job may take several minutes; do not leave the page until it completes.

The analysis uses the R package:

  • Distance: Detection function fitting and density estimation via dht2.
